# Node Todo List

This repository contains a Node.js backend and a frontend for a simple todo list application.

## Structure

- `backend/` - Node.js backend code and documentation.
- `frontend/` - Client-side application assets (`app.js`, `index.html`, `style.css`).

## Getting Started

1. Open the `backend` folder and follow the instructions in `backend/README.md`.
2. Open `frontend/index.html` in a browser to use the frontend.

## Notes

- Ensure the backend is running before using the frontend if they are integrated.
- The backend README contains more details about setup and usage.
