# 🚀 TaskMaster REST API (Backend)

A lightweight, RESTful web API built with **Node.js** and **Express.js**. This server acts as the backend data engine for the TaskMaster full-stack application, serving JSON data and handling CRUD (Create, Read, Update, Delete) operations over HTTP.

---

## 🛠️ Tech Stack & Dependencies

* **Runtime:** Node.js (V8 Engine wrapper)
* **Framework:** Express.js (Fast, unopinionated web framework)
* **Middleware:** CORS (Cross-Origin Resource Sharing)
* **Dev Tool:** Nodemon (Auto-restarting development server)
* **Database:** In-Memory JavaScript Array (Temporary RAM storage)
